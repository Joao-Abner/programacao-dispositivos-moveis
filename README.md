# 📱 Programação para Dispositivos Móveis

Este repositório armazena todas as atividades práticas e projetos desenvolvidos ao longo da disciplina de **Programação para Dispositivos Móveis (PDM)**. 

O foco central da disciplina é o desenvolvimento de aplicações mobile multiplataforma (Android e iOS) modernas.

## 🛠️ Tecnologias Utilizadas

As principais ferramentas e tecnologias que estão sendo exploradas neste repositório incluem:

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [TypeScript](https://www.typescriptlang.org/) / JavaScript
- Componentes funcionais e Hooks (`useState`, `useEffect`, etc.)

## 📂 Estrutura de Atividades

Aqui estão os links rápidos para os diretórios das atividades desenvolvidas:

- [Atividade 1: Interpolação](./atvd-interpolation) - Criação de catálogo dinâmico usando `.map` e interpolação.
- [Atividade 2: Estilização](./atvd-styles) - Aplicação de Flexbox e StyleSheet no React Native.
- [Atividade 3: Hook useState](./atvd-use-state) - Manipulação de estados e reatividade em componentes.
- [Atividade 4: Hook useEffect](./atvd-use-effect) - Ciclo de vida e efeitos colaterais.
- [Atividade 5: Listas e FlatList](./atvd-listas) - Renderização performática de listas longas.
- [Atividade 6: Screen Wrappers](./atvd-screen-wrappers) - Componentes de encapsulamento e SafeArea.
- [Atividade 7: Expo Router](./atvd-expo-router) - Navegação moderna baseada em arquivos.
- [Prática de Implementação 1](./implementacao-pratica) - Projeto consolidado de nível Júnior.
- **[Prática de Implementação 2: Estoque Erva-Mate](./implementacao-pratica-2)** 🌟 *(Projeto Atual)* - App mobile completo de CRUD com autenticação global via Context API, persistência local com Async Storage, proteção de rotas, integração a servidor remoto PocketBase REST e testes unitários Jest.
