# 📱 Programação para Dispositivos Móveis

Este repositório armazena todas as atividades práticas e projetos desenvolvidos ao longo da disciplina de **Programação para Dispositivos Móveis (PDM)**. 

O foco central da disciplina é o desenvolvimento de aplicações mobile multiplataforma (Android e iOS) modernas.

## 🛠️ Tecnologias Utilizadas

As principais ferramentas e tecnologias que estão sendo exploradas neste repositório incluem:

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [TypeScript](https://www.typescriptlang.org/) / JavaScript
- Componentes funcionais e Hooks (`useState`, `useEffect`, etc.)
